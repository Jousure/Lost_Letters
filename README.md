## 🌟 Overview

**Lost Letters** is a full-stack web application that delivers vintage-style fictional love letters centered around tragic romance, longing, and separation.

The backend provides a REST API built with **FastAPI**, and the frontend is developed using **React**. The project focuses exclusively on emotional, old-world tragic love letters presented through a clean and nostalgic interface.

## ✨ Features

- 💔 Random tragic love letters  
- 📜 Fetch letter by ID  
- 📡 JSON API responses  
- 🎞 Vintage aesthetic frontend  
- 🔌 Clear backend and frontend separation  
- ➕ Easy to expand with new letters

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Jousure/Lost_Letters.git
cd Lost_Letters
```

---

### 2️⃣ Run Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

Backend runs at:

```
http://127.0.0.1:8000
```

---

### 3️⃣ Run Frontend

```bash
cd frontend
npm install
npm start
```

---

## 📡 API Endpoints

| Method | Endpoint | Description |
|--------|----------|------------|
| GET | `/letters` | Get all letters |
| GET | `/letters/random` | Get a random letter |
| GET | `/letters/{id}` | Get letter by ID |
